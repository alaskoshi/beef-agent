# Three-minute local rehearsal

Cast: Jules (RIVET, designer), Rowan (FORGE, shipper), host/referee/hype, producer. All fictional. Minimum live cast: two speakers plus one host/hype; operator may double. Trainers are the bounded application workflow; a consenting person can voice the card and should say so.

Before starting: 1440×900, fresh bout, sound off until enable gesture, headphones/levels checked, choose Bedrock and verify account session, keep private notes empty. Three-minute timer is a pacing target; Long rehearsal uses the same state machine with 120-second phases. No navigation, X setup or device switching during presentation.

| Time | Voices and cue ownership |
|---|---|
| 0:00–0:15 | Host: “Where’s the beef? Jules and Rowan shipped a project together. One name didn’t make the credits. Bring your beef. Bring your corner.” Producer: enable audio; distinct short walkouts; no noise over the first line. |
| 0:15–0:32 | Bell. Jules: “You shipped our shared project without crediting me. You clearly think I did nothing.” Producer: Jules floor; enter L1, or use the explicitly labeled fixture. |
| 0:32–0:50 | Rowan: “I never said you did nothing. The demo moved to ten. I shipped before the credit slide was ready.” Producer: Rowan floor; L2. Host: “That’s the first exchange. Take your corner.” |
| 0:50–1:20 | Corner cue. Producer: Jules, clarify objective, Bedrock; request a fresh card. Show exact L2 and synthetic R2/R3. Trainer voice reads ONE adjustment, not the whole card. Jules chooses/edits: “I accept the demo moved. R2 explains the timing, but R3 still leaves my name out. Can we correct the credit today?” The human’s edit is explicit. If inference fails, say so and explicitly select the rules rehearsal. |
| 1:20–1:43 | Bell. Jules speaks the edited reply, then pauses. Producer enters the approved line. Host, only after the line: “Bring that point back clean.” Producer may confirm receipt cue. |
| 1:43–2:05 | Rowan: “Yes. Your design work belongs in the credits. I will add it today. We still need a shared sign-off rule.” Producer: log response and, if appropriate, confirm concession. Host: “A concession counts. Now show them you heard it.” |
| 2:05–2:35 | Steel exchange. Jules: “You were meeting a changed deadline, not saying my work had no value.” Rowan: “Your grievance is missing public credit, not that I shipped quickly.” Allow each one correction; no indefinite veto. Producer: steelman cue after acceptance. |
| 2:35–2:55 | Host: “Credit gets corrected today. The release sign-off rule is still unresolved. That’s split beef.” Producer: ending, confirm summary, participants acknowledge where appropriate, choose SPLIT BEEF. For BEEF SQUASHED, both must explicitly acknowledge reconciliation; do not infer it. |
| 2:55–3:00 | “Fictional rehearsal. Manual transcript. Live model corner. Producer-cued stage. X unverified.” |

Hype cue cards: “Where’s the beef?” / “Take your corner.” / “Let them finish.” / “Now answer the actual point.” / “That concession counts.” / “Name what changed.” Silence between cues is intentional.

Stop rule: anyone may withdraw. Operator clicks Stop bout; no forced reconciliation, disclosure, or final insult. Local audio stop does not mute a real Space.

Recording fallback: synthetic local system voices, captioned, visibly PRERECORDED REPLAY. It is useful for timing and reproducibility; it does not prove live human delivery. Rehearse twice without code changes before replacing it with the owner-approved final performance.
